\noindent\textbf{Dev Chodavadiya}:
I think the project went well overall. The team did a good job splitting up the work and communicating when things needed to come together. On my end, the 3D printing process took more iterations than expected to get the plates flat and properly aligned, but working through those issues taught me a lot about designing for manufacturability. I also worked on the feature of having the user signout everywhere, and as well deletion of the users account. If there was one thing I would do again, I would start the CAD and printing process earlier to leave more room for iteration. I think I would want to get more involved on the security side of this project, because I feel like that is an important area to improve my knowledge in.\\
\\

\noindent\textbf{Logan Bossuwe}:
The project went overall well coordinated roles. Collectively, we had a good idea of our needs and goals statement to work into a clear design path. We followed our planned schedule of implementations well and constantly kept communicating what was done. One thing we could have done better is to properly plan out an aesthetic prototype earlier and make it more flexible towards adding other additions to the circuit, such as a reset button. The current prototype does not have enough space and would need a reprint in order to design for a button/other features. What I could have done better is to start soldering the board containing the microcontroller and load cell amplifier earlier for our functional prototype. This would allow the rest of the team to have a clearer map of what was needed for the aesthetic prototype.

\noindent\textbf{Pieter Nauwelaerts}:

I think we had a clear idea of which sections we wanted to put work into, and overall everyone was able to get an idea of what was happening at each corner of the design. One thing I think we could have done differently is trying to get another microcontroller running the code so we could imagine what it would look like to have two devices connected to one user account, and test functionality like notifications that way as well.

\noindent\textbf{Sam Lai}:

\noindent\textbf{Shriyan Gote}:
I think the project went well overall. Getting the BLE provisioning working end-to-end  from the firmware side on the microcontroller all the way through to the React Native app on iOS was the most rewarding part, since it required both sides to work together correctly at the same time. If I were to do it again, I would start development earlier to leave more room for iteration, especially on the firmware side where debugging can be slow. I would also focus more on testing the BLE and WiFi provisioning flows under different conditions, and I would like to add a few additional features to the mobile app, such as customizable notification thresholds and more detailed device status views.\\
