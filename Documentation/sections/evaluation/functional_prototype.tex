\subsection{Functional Prototype}
The prototype will consist of weight sensor readings sent to HTTP server via POST. Webapp will be shown using fake data to demonstrate
handling of data in grams with notifications

\noindent\textbf{Hardware Setup}
The plates used above and below the load cell are made for functional prototype purposes to fit the need of measure weight readings rather than
handling various brita water pitchers. Temporary HTTP server made to display and mimick how data is shown/handled.

\noindent\textbf{Webapp Setup}
One computer will input data and another will be displayed to show notifications on the webapp.
