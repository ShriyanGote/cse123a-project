\subsection{Amplifier}
In order to get readings for weight from the load cell, it is most likely required to use an amplifer if the chosen load cell is analog.

\subsubsection{Digital Converter}
Software will need to be implemented in order to read data, analog gives the signals in terms of bits that need to read and converted to either raw data of calibrate straight to grams.

\subsubsection{Average Sampling}
Sampling without averaging can lead to lots of noise. Average sampling allows the accuracy of weight to be more accurate.

\subsubsection{Tare}
For handling offset, it is required to create to create a baseline state value that represents an empty pitcher. It means future data is can be compared to the baseline value to get the water weight readings.
