\subsection{HX711}
This file will show the necessary components to be able to collect/read data from the HX711 sensor to your microcontroller.
The goal is collect sensor readings, convert the readings to grams. Includes documentation of wires.

\subsubsection{SCK}
    \begin{itemize}
        \item SCK is the clock line.
        \item Controls when bits are shifted out of DOUT, each pulse moves the next data bit to the output.
        \item SCK LOW->HIGH - Shifts out one bit
        \item SCK HIGH for some time - Power down mode
        \item LOW after power down - Sensor wakes up and converts data
    \end{itemize}

\subsubsection{DOUT}
    \begin{itemize}
        \item DOUT, Data output that sends 24-bit measurement to microcontroller
        \item DOUT HIGH - HX711 currently converting data not ready
        \item DOUT LOW - Data is ready to read
    \end{itemize}

\subsubsection{Pins}
    \begin{itemize}
        \item VCC - power supply around 2.7-5.5V
        \item GND - Ground
        \item E+ - Positive excitation voltage
        \item E- - Negative excitation voltage
        \item A+ - Positive signal input, Chanel A
        \item A- - Negative signal input, Chanel A
        \item B+ - Positive signal input, Chanel B
        \item B- - Negative signal input, Chanel B
    \end{itemize}

\subsubsection{Read Data}
The HX711 Sensor is a 24-bit analog to digital converter. To read data, you will need to be able to read the raw 24bits.
The wire that matters here is SCK, since SCK is a pulse that will shift 1 bit each time, you need to do this 24 times for the full
number. Additionally, there are extra pulses needed for the HX711 to select Chanel. This is inferred as my define PULSES\_TOTAL 25.
Create a delay when waiting for DOUT to go low again, sometimes it might stay high.

\subsubsection{Average Sampling}
Sometimes, the sensor will spike its readings. Average sampling allows us to deal with outliers.

\subsubsection{Calibration}
The Sensor gives raw data, as counts. From testing, have a hard coded number that when using to calculate the grams from the raw data, 
just divide raw by the hard coded number. Use known weights to calibrate accuracately.

\subsection{Tare}
For handling offset, tare function will take the current weight to zero. Whenever an object is placed later, the weight displays is sampling - offset.
Sampling gives total weight, offset allows to remove the pre-existing weight to display the objects true weight.

\subsubsection{Debug}
Print statements every second each signal/number:
\begin{itemize}
    \item SCK
    \item DOUT
    \item Raw Sample
    \item Offset
    \item Grams
\end{itemize}
Allows to bugs/problems code or hardware related.
